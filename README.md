<h1>Izdelava registracijskega obrazca v Android Studio</h1>

V Android Studiotu sem izdelal Registracijski obrazec,
ki ukljucuje vnosna polja za podatke:
1. Username
2. Fullname
3. Country
4. Email
5. Phone number
6. Gender (Male/Female)
7. Password
8. Checkbox za terms and conditions

Dostopno je tudi na manjših zaslonih zaradi uporabe ScrollView.
